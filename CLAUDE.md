## Project

Static website for **Donner de la Voix** — singing lessons and vocal improvisation workshops in Toulouse. Vanilla HTML/CSS/JS, no framework.

## Commands

```bash
npm install          # Install dev dependencies
npm run dev          # Start local dev server on http://localhost:3000 (with Vercel-like rewrites)
npm run build        # Generate env-config.js from environment variables (run before deploy)
```

No test runner is configured.

## Architecture

### Page structure

- `index.html` — homepage
- `pages/*.html` — all other pages (served via URL rewrites, e.g. `/ateliers` → `/pages/ateliers.html`)
- `partials/header.html` — shared header injected at runtime via `js/init-header-nav.js` into `<div id="site-header">`
- `partials/floating-rdv.html` — floating Calendly button injected via `js/init-floating-calendly.js`

URL rewrites are defined in `vercel.json` (production) and replicated in `scripts/serve-with-rewrites.js` (local dev).

### JavaScript

All pages load `js/init-header-nav.js` (plain script) and `js/init-floating-calendly.js` (plain script) for the shared UI. The `ateliers.html` page additionally loads `billetweb-config.js` then `js/main.js` (ES module) for workshop data.

`js/main.js` is the ES module entry point for the ateliers page. It imports:
- `js/components/` — menu, workshops, calendar, navigation, hero-dropdown, header
- `js/services/billetweb-api.js` — fetches workshops from BilletWeb API, with 15-min localStorage cache (`js/services/cache.js`)
- `js/utils/` — security (sanitizeExtId), image URL conversion

**Script load order matters**: on pages using BilletWeb, `secrets.local.js` → `billetweb-config.js` → `main.js` must be loaded in that order.

### Configuration & secrets

- `secrets.local.js` — local dev secrets (not committed); copy from `secrets.example.js` and fill in values. Sets `window.SECRETS`.
- `billetweb-config.js` — reads from `window.SECRETS` and `window.ENV`, builds `window.BILLETWEB_CONFIG`
- `emailjs-config.js` — EmailJS public config
- `env-config.js` — generated by `npm run build` from environment variables for production

### Backend / API

- `api/billetweb.js` — Vercel serverless function acting as a proxy to the BilletWeb API. Reads credentials from environment variables (`BILLETWEB_USER_ID`, `BILLETWEB_API_KEY`, etc.). The BilletWeb API key must never be exposed client-side.

### Design system

CSS variables defined in `styles.css`:
- `--color-deep-bg`: `#0d0218` (dark purple/navy background, used site-wide)
- `--color-primary`: `#5b2ab5` (purple)
- `--color-accent`: `#cf3594` (pink/rose)
- Teal (`#4db8aa`) used for decorative elements and bento card tints
- Font: Inter (Google Fonts), weights 300–700

### Deployment

Deployed on Vercel. `vercel.json` handles URL rewrites and the build command. The `_headers` file is for Netlify deployments (security headers).
